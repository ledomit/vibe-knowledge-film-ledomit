# ledo 风格的来源：参考片拆解

参考片：抖音「VibeSCI」一条讲高速原子力显微镜（HS-AFM）拍下肌球蛋白走路的片子，188 秒，1280×720，30 fps（用户 2026-10-25 提供）。
拆法：每 2 秒抽一帧拼图、检测硬切、检测字幕区和全画面的变化时刻、量配乐的拍子，再把变化时刻和拍子对齐。

## 二、节奏和卡点

- **配乐**：约 112 BPM（一拍 0.534 s），和仓库里的 `bgm.mp3` 同速。段落：0–17 偏轻（钩子）· 18 起变满（揭晓）· 82–98 抽空（"攻关卡住了"）· 98–102 重新进入（"2010 年终于成功"）· 166 起淡出（片名和 logo）。
  **配乐的起伏和叙事的起伏严格对应**：最大的揭晓卡在配乐变满处，"卡住"放在抽空段，"成功"放在重新进入。
- **几乎不硬切**：188 秒只有 4 个硬切（55.8 人物照片、89.1、162.1、166.4 片名）。其余全靠**连续镜头**串起来：推进照片/书页/屏幕里面、从一张图"长出"另一张、胶片条、白场。
- **字幕**：约 38 次切换，中位间隔 2.8 s；**58% 落在拍上**（±90 ms，随机约 34%）。画面大变化中位间隔 2.9 s，42% 落在拍上。
  → 它是**叙事型卡点**：重要的出现（揭晓、年份、真实影像弹窗、金句）卡拍，过程性的推拉不强求。
- **信息密度**：每 2–3 秒一个新信息点（一句字幕或一个新元素），188 秒讲完一段 40 年的科学史。

## 三、动画和画面设计

1. **真实素材 + 3D 混排**：课本实拍、人物照片、地图、楼的照片、论文页、真实显微影像，和 3D 分子模型放在同一个空间里；真实素材都带"物件感"（拍立得白边、阴影、轻微透视、贴在板上/挂在夹子上）。
2. **"REAL FOOTAGE · 真实影像"小窗**：右上角弹出、带细边框和等宽小标，和主画面的 3D 用编号圈（①②）一一对应——"模型是这样，真的也是这样"。
3. **金色大年份**：衬线大数字（1989、2002），下面一行等宽小字说明（"ANDO STARTS · 开始用 AFM 看蛋白质"）；配地图上的定位点和一根细引线。
4. **标注语言**：细引线 + 等宽大写小字 + 中文（"MYOSIN V · 肌球蛋白 V""TRACK · 轨道"），编号圆圈，四步清单逐条点亮。
5. **复古设备当画框**：CRT 显示器、秒表、胶片条、论文打印页——把"时间慢""年代感"做成看得见的东西。
6. **字幕版式**：**左下角、左对齐**，左边一条细竖线；中文粗黑体白字一到两行 + 下面一行小号灰色英文；**金句**改成居中、金色、加大。
7. **色彩**：近黑的炭灰底 + 金色（年份、金句、高亮）；3D 场景用青绿；真实 AFM 影像是橙黄；整体克制，只有金色是强调色。
8. **防盗水印**：画面中间斜着一行很淡的"@VibeSCI"。
9. **首尾呼应**：开头的课本在 158 秒回来，同一页上点亮一个词，意思升级。

## 四、右上角的 logo

- 常驻在右上角：灰色小字"@VibeSCI" + 一个约 36 px 的圆形徽标（深蓝球体、一道弧形高光、一颗小星），透明度约七成，全片不动。
- 片尾 logo 动画（178–184）：暗场中一道带光点的弧线绕圈画出圆 → 圆里浮现球体和"VibeSCI"字样 → 停住。

## 六、逐秒重看（2026-10-29，每秒一帧 + 16 张关键帧）：画面到底由什么组成

一句话：**它不是"动画片"，也不是"照片集"，而是把五种材料放进同一个物理空间里，用一台连续运动的镜头串起来。**

### 6.1 五种材料（ledo 的"画面词汇表"）

| 材料 | 参考片里的例子 | 处理手法（这是风格，要固化） | 我们的件 |
|---|---|---|---|
| **实物** | 课本躺在木桌上；论文页（PRL 1986、Nature 2010、Nature Reviews Physics 2026）；一摞期刊书脊印着年份；夹在灯下的人物照；打印机吐出一页纸 | 有厚度、有阴影、斜放在桌面或悬在空中，镜头从斜上方推近；纸张偏暖白、带暗角 | `L.paper` `L.plane3` `L.photo` `L.portrait` |
| **真实影像** | 琥珀色 AFM 视频、粉色肌肉切片、灰色电镜、绿 / 粉荧光、黑白老 AFM 图 | 一律"框起来"：小窗、CRT、显示器、论文图里；上方等宽小标 + 下方出处；不铺满不调色 | `L.footage` `L.crt` `L.video` `L.compare` |
| **3D 模型** | 粉彩蛋白（淡蓝 / 淡黄 / 淡紫的小球团）在青绿色细胞里走；灰白色仪器（早期 AFM、样品台、悬臂）；金色悬臂 | 有体积、顶光、景深、远处雾化；**模型和实物在同一空间**：3D 膜从课本封面长出来，AFM 模型放在论文页上 | `L.cam3` `L.molecule` `L.blobs3` |
| **HUD 标注** | 编号圈 ①②；等宽大写英文 · 中文的引线标注（ARM · 杠杆臂）；左上步骤清单；秒表 00:09→3 min；比例尺；波形；计数器 100→76→40 | 细线、等宽字、灰白；只指不画，不抢主体 | `L.marker` `L.callout` `L.checklist` `L.clock` `L.scaleBar` |
| **字** | 左下竖线字幕；金色衬线大年份（1986、1989、1993、2010、2011、2017、2026）；居中金句；竖排宋体片名；左上一行出处 | 金色只给"时间"和"结论"；出处每张图都有 | `L.sub` `L.year` `L.citation` `L.endLogo` |

### 6.2 五种"证据动作"（让观众相信"这是真的"）

1. **荧光笔划过论文**：标题里关键词（"walking myosin V"）、作者行（"第一作者 · 学生 古寺"）、课本里的一句话（"承担"）被黄色笔迹涂过 → `L.paperMark` / `L.highlight`。
2. **红章否定**：只能拍静止照片 → 红色"STATIC"章盖在图上 → `L.stamp`。
3. **左右对照**：真实影像 vs 3D 模型同步走（同一个计时 8.33 s / 9.33 s / 14.66 s）；荧光 vs AFM（"以前只看得见一个亮点"）→ `L.compare`。
4. **同一个机位的"以前 / 现在"**：同一张实验桌，1986 年的老设备 → 2026 年的新设备，金色年份在角落换掉 → 用一个场景函数，按年份切换道具。
5. **计数和计时**：秒表从 00:09 走到 3 min；"改进次数" 100 → 76 → 40；拍一张图 80 ms → `L.clock`、大数字滚动。

### 6.3 镜头和转场目录（188 秒只有 4 个硬切）

| 手法 | 参考片 | 怎么做 |
|---|---|---|
| 钻进实物 | 镜头推进课本封面 → 翻开 → 停在第 4 节 | `L.plane3` 推近（相机 `dist` 变小）→ `L.pushThrough` |
| 从实物里长出模型 | 课本上长出 3D 细胞膜；AFM 模型立在论文页上 | 先画 `plane3` 的纸，再在纸面坐标上画 `blobs3` / 仪器 |
| 放大尺度链 | 课本插图 → 肌肉切片 → 电镜 → 3D 细胞内部 | 每一级都是"上一级画面中心的一个点"，连续推近 + 白场 |
| 屏幕里的世界 | 论文出现在显示器上；3D 场景缩进显示器 | `L.crt` / `L.grow` |
| 环绕 | 3D 蛋白镜头绕着转、景深变化 | `L.cam3` 的 `yaw` / `pitch` 随时间走 |
| 胶片条 / 打印 | 一格格影像飞过；打印机吐出论文 | `L.filmstrip`；纸从设备里往上推 |
| 同机位换年份 | 1986 → 2026 的实验桌 | 一个场景、两套道具、年份交叉淡 |

### 6.4 颜色语义（全片不破例）

青绿 = 细胞内部的世界 · 粉彩蓝 / 黄 / 紫 = 蛋白质 · **琥珀 = 真实 AFM 影像** · 绿 / 粉 = 荧光 · 灰白 = 仪器和历史 · **金 = 时间与结论**（年份、金句、字幕竖线、高亮）· 红 = 否定 / 限制（STATIC 章）· 暖黄 = 纸和荧光笔。

### 6.5 节奏（数出来的）

- 每 2–3 秒一个新信息点；每段 3D 过程 6–12 秒，中间插一张"证据"（论文、照片、影像）让观众歇一下。
- 一个概念的标准段落：**问题（字幕）→ 3D 演示 → 真实证据（小窗 / 论文 / 对照）→ 年份 + 人**。
- 揭晓（"这，就是蛋白质走起路来的样子"）用居中金句 + 真实影像弹窗同时出。

## 七、哪些固化进 ledo，哪些是这条片自己的

**固化（风格）**：五种材料同空间、实物有厚度和阴影、真实影像必须加框加出处、3D 粉彩 + 顶光 + 雾化、五种证据动作、金色只给时间和结论、HUD 等宽小标、连续镜头少硬切、左下竖线字幕、片尾弧光 logo。

**不固化（一次性设计，换题目就要重想）**：肌球蛋白的走路动画本身、AFM 的激光反射波形、课本"第 4 节"的具体页面、日本地图和金泽的定位、"四十年"期刊摞的具体年份、科学家照片墙的人选。这些是**这个题目的形象**，按 `visualization.md` 第五节重新找，不要搬。

同理，我们自己做过的片子里一次性的设计（例如《人生无法预测》的门牌翻面、排名卡、人生曲线、碗口圆窗）也不进 skill。
