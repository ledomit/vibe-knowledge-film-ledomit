# keben（课本）：真课本翻开，插图长成真的，荧光笔划出那一句

一本真的课本（用户给的 PDF，每一页都是原页）在暗场里翻开，停在那一课。页上的插图破纸长成 3D 的实物（花、树……）。
一阵风吹落花瓣，镜头顺着落花推近正文，荧光笔跟着旁白一截一截划出那一句。
旁白是港台老电影国语配音那种女声，念的就是课文原句；配乐卡拍，全片 ≤ 20 秒，说完后配乐渐弱。没有字幕。

来源：AI_films_editing 仓库 `films/04-fanshu/`《翻书·丁香结》v11（19.76 s，统编版语文六上第 2 课）。**示例工程 `examples/keben_demo/`**：就是那条片子的 film.js 和配置，不带课本页面（版权），用 `scripts/keben_pages.py` 从 PDF 渲出来就能跑。

| 适合 | 不适合 |
|---|---|
| 课本里的名篇名句、"小时候背过的那一句"、要共情的短片；一个画面一句话就够的题目 | 要讲清一个机制的讲解片（用 C / ledo）；口播攻略（用 card） |

和 skill 主规矩的不同：**有旁白、没有字幕**（课文原句就在书页上，用荧光笔"念"给观众看）；时长 15–20 s，不是 2–5 分钟。

## 一、提示词

**中文 brief（填空）**

> 做一条 keben 风格的翻书短片（16:9，≤ 20 秒）。课本用这个 PDF：〈路径〉，翻到 PDF 第 〈偶数〉/〈奇数〉 页（《〈课名〉》）。必须用真实 PDF 的页面，配对和真书一致。
> 右页那幅〈插图〉从画里对应的位置破纸长出来，变成真的 3D〈实物〉。形状照真〈实物〉查证，颜色取自画（浅、像画，不要长完变白）。
> 长全的那一拍正好落在配乐最重的军鼓上。然后一阵微风吹落〈花瓣〉，镜头顺着落花推近右页正文，荧光笔只划〈那一句〉，跟着旁白念到哪划到哪。
> 配乐：〈mp3〉，卡鼓点，后面渐弱。旁白不加字幕，港台老电影国语配音的女声，细腻、煽情但不过，前后语气一致，带一点电影对白的后期混响。
> 第一句旁白〈……〉配翻书 + 长出来，第二句〈……〉配推近 + 划线。

**English brief**

> A ≤20 s 16:9 "keben" textbook film. Use the real PDF pages (correct spread pairing) and flip to the 〈lesson〉 spread. The 〈illustration〉 on the right page grows out of the paper at its own position into a real 3D 〈object〉: botanically correct shape, colours sampled from the painting, light and painterly, with no whitening at the end. Full bloom lands on the strongest snare. Then a breeze scatters 〈petals〉, the camera follows them into the body text, and a highlighter marks only 〈the sentence〉 in sync with the voice. The BGM is cut to beats and fades after the last word. Voice: a 1990s Hong Kong film Mandarin-dub young heroine, delicate, moving but restrained, with consistent tone and light dialogue reverb. No subtitles.

## 二、结构（按拍算，不写秒数）

以 bgm_zijie（111.4 BPM，一拍 B = 0.53874 s，第一个下拍 D0 = 0.364，片长 36 拍 = 19.76 s）为例。`BEAT(b) = D0 + b·B`，`DB(k)` 第 k 小节下拍，`SN(k)` 同小节第 3 拍军鼓。

| 段 | 拍 | 画面 | 旁白 | 声音 |
|---|---|---|---|---|
| 翻书 | 0 – 2 | 第 0 帧就在翻：封面 + 4 张内页，每张落在一个八分音符上；第 2 拍停在目标跨页。镜头从斜俯（44°，偏 −16°）转到正俯 23° | 第一句第一截钉在第 0 拍 | 每张 `flip`，"啪"对准落纸那一拍 |
| 破纸 | 3 – 4 | 画里枝条处一个光点 + 一圈涟漪 → 枝条长出、分叉 → 叶子成对展开；纸上的画淡下去 | "都有许多不顺心的事" | `soft` + `rise` |
| 冒花 | SN(1) 起 | 先冒两串花序；念到"一件完了，一件又来"再一串接一串冒（每个十六分音符一串）。下半截边长边开，上半截憋着 | "一件完了，一件又来" | `shimmer` |
| **揭晓** | 全曲最重的军鼓 | **上半截一起开，花全开**；镜头停在花上（60° 侧看） | 关键词（"丁香结"）钉在这一拍 | `bloom` + `shimmer` |
| 起风 | 第二乐句下拍 | 一阵风：整枝顺风弯、小花抖，低处一部分被吹落、翻飞、落在两页上；镜头顺着落花推向正文 | "年年都有" | `wind` |
| 划线 | 第二句第一字（军鼓） | 推到正文；荧光笔跟着旁白每截划到哪 | 第二句 | 每截一声 `marker` |
| 收 | 说完后 | 慢推（0.8 → 0.64）；最后 0.9 s 渐黑 | — | 配乐说完 0.09 s 后 cos² 渐弱到片尾 |

前 2 秒：第一帧就在翻书，旁白第一句开口。5 秒左右：花序一串串冒出来。最大的揭晓（花全开）放在最重的鼓点上，同时念到片子的关键词：画面、提示音、人声三样一起落。

## 三、画面规格

### 书（真的 PDF）

- **页面**：`python3 scripts/keben_pages.py <课本.pdf> <工程> --to 11 --hi 10,11`，出 `assets/pages/pNN.jpg`（高 1301）。目标跨页另出 `_hi`（高 2601），推近用。脚本会打印页宽高比 `PW` 和翻页表 `LEAVES`。
- **配对和真书一致**：p1 封面单独在右，之后左偶右奇 `[p2|p3] [p4|p5] …`。拿目录或插图跨页核对，两半拼得上就对了。每张翻的纸正面是奇数页、背面是偶数页；目标跨页的右页（奇数）是不翻的底页。
- **画法**：WebGL 画在 `fr.look.under`（不进辉光）。外观 `theme: 'night', bloom: .6, grain: .035`，背景 `bgo.stars .35`，书下一层暖色径向光 `rgba(255,226,190,.13)`。
- **几何**：页高 1、宽 PW，书厚 T = 0.027。每张纸是 48×16 的网格，按行积分卷页：外缘、上角先起，卷曲参数 0.42。落到左边的角度 `thEnd = π + asin((T − zl(i)) / PW)`，左边那一沓逐张抬高。
- **光**：Lambert 光（主光从左上来），加一盏跟着镜头目标走的聚光。另有书沟阴影（`vT.x` 指数变暗）、翻页投影（最多 5 张同时投）、带噪声的纸边，封面侧边是橙色。
- **相机**：关键帧 `[时刻, 目标 x, y, z, 俯角°, 偏航°, 距离]` 缓动，FOV 30°。开场斜俯 → 正俯看跨页 → 揭晓时停在花上 → 起风后才推 → 正文（17°，0.8）→ 慢推到 0.64。

### 插图长出来（2D → 3D）

用户反馈总结出来的六条：

1. **不要把画切成碎片飞成 3D**：会杂乱，像从中间突然冒出来。要从画里对应的位置**破纸长出来**：光点 + 涟漪 → 枝 → 叶成对展开 → 花序沿花轴从下往上冒苞 → 苞从下往上开。
2. **形状照真东西查**。丁香的花冠四裂，裂片长卵形、圆头；花序是圆锥形；叶宽卵形、基部心形。花瓣是一块方片，片元里按长卵形裁。用 `window.MACRO` 出一张特写确认。
3. **颜色取自画，浅、像画**（`tools/make_lilac.py` 从页面取遮罩和颜色）。**长出来就是这个颜色，不要"长完变白 / 变色"的特效**：花苞颜色 ≈ 开花颜色，只有顶端偏粉。枝从浅灰褐过渡到浅绿，叶是画里的灰绿，从 (.5,.6,.45) 到 (.66,.74,.56)。
4. **纸上的画淡 42%**（`uFade`），让立体的那枝做主角；再加一块投影。
5. **整体形状先出 4–5 种给用户挑**（`TREES.A–F`，用 `tree.js` 里的 `window.TREE` 选，一种出一张生长图、一张盛开图）。
   丁香的教训：伸出几根尖就像五角星，太圆就像个球，最后取了中间。中间那版的参数：方向往上收 0.25，花序轮廓 `(1 − s^1.3)^0.75`，十串花序。
6. **光点**（`fr.spark`）画在内容层，带辉光：长的时候枝头、花轴头各一颗；开花时每朵花附近冒一点光往上飘。

### 风和落花

- 揭晓之后一阵微风：0.35 s 起，2–3 s 收。整枝顺风弯 0.11 rad，小花轻抖。
- 低处约 14% 的小花被吹落：翻飞，缩到 0.42，最后平躺在两页上。**落点避开要划线的那几行**，正文区少落一些。
- 镜头顺着落花推向正文，推近和落花是同一个动作。

### 荧光笔

- 在页面贴图坐标里画，跟着纸的透视走。每行一个矩形，坐标用原图像素 ÷ 尺寸量出来。
- 乘色黄 (1, .86, .26) × 0.78，边缘毛一点，从左往右扫。
- **只划旁白念的那一句**。跟着旁白每截划到哪：`voice.json` 的 `hl` 写每一截对应第几到第几个字，每截配一声 `marker`。

### 结尾

最后 0.9 s 渐黑。用户说不要字幕时，片名和文献也不上屏；要加的话，放在渐黑前的正文画面上。

## 四、卡点：先排旁白，画面跟着旁白

1. **先量配乐**：BPM、第一个下拍、军鼓在第几拍、全曲最重的一记、乐句从哪开始。配乐不改，片长取前 N 拍。
2. **旁白先排好**（`keben_voice.py place`），产出 `vo_timing.js`。画面节点全读 `window.VO.marks`（`pan` 冒花、`burst` 花全开、`wind` 起风、`s2` 第二句、`end` 说完），film.js 里不手写秒数。改了旁白，画面自己跟着挪。
3. **钉拍**（`anchor`）：第一截钉第 0 拍；"所以"这类转折词钉下拍；关键词钉全曲最重的军鼓（= 花全开）；第二句第一个字钉军鼓。别的截按自然停顿排，对到十六分音符上。
4. 翻页事件的时刻 = 起翻，`dur` = 落纸拍 − 起翻，这样"啪"落在拍上。

## 五、配音

- **声线**：Gemini TTS `Achernar`，风格提示词见 `examples/keben_demo/voice.json` 的 `style`。
  用户说的"港台磁性"，指的是 90 年代港片国语配音里的年轻女主角：清亮、甜润、带气声、台式软糯咬字，约 4 字/秒。**不是低沉**。
  用户给参考音频时，先问过能不能上传，再用 `keben_voice.py ask` 让 Gemini 分析声线。
- **两句一口气念完**（`text` 是全文，靠标点控制断句）。分开生成，第二句的语气会变。
- **表演指导要收着**：写"moving but restrained"，停顿和呼吸"都不要太过"。"气声、叹息"写多了，声音会变虚、变慢。
  要压住某一句往上扬，就在 `act` 里点名："keep 〈那句〉 calm and low like the rest"。
- **每次出 3 版，用测量挑**：`keben_voice.py stats` 测每一截的音高，挑"最高的长截"数值最小的那版。长截 ≥ +1.5 半音，听起来就是"突然抬高"。
  Gemini 判"稳不稳"不可靠：同一条先打 9.2 分、后打 6.5 分。它只做最后一遍整体复核。
- **排进时间轴**（`place`）：
  - 按 ≥ 0.2 s 的停顿切截；截间停顿压到 [0.14, 0.55] s。
  - 每截前留 0.2 s 吸气（淡入），后留 0.1 s 尾音。
  - 没钉拍的截对十六分音符：对八分音符会把停顿撑到 0.6 s 以上。就近取整时，不得比想要的位置早 0.05 s 以上。
  - 各截响度往中位数拉一半，最多 ±3 dB，音高不动。
- **额度**：只有用户明确说要配音时才跑 `tts`（每天额度很少），两次调用至少隔 7 s。遇到每日额度用完的 429 就停下告诉用户。改文案时先用 `place --estimate` 出静音占位。

## 六、混音和交付（`scripts/keben_mix.py`）

- **配乐**：取前 N 拍，整体常数增益 −10.5 dB（有旁白），不闪避、不改形状。旁白说完 0.09 s 后 cos² 渐弱到片尾，这只在用户要了"渐渐消失"时才做。
- **旁白**：加一点电影对白的后期混响，t60 0.75 s、wet 0.1。用户喜欢这个质感，但别再加多。
- **动效**：放在旁白峰值下 9 dB；只在会削波的几毫秒里局部压低动效。
- **交付** `final/<片名>_vN_完整版.mp4`、`_仅动效配音.mp4`、`_动效配音.wav`，并校验"完整版 − 动效配音 − 配乐 ≈ 0"。

示例的 film.js 里，能整块搬走的是**书**、**相机**、**荧光笔**和**小花着色器**。它们是这套外观本身：`sheet` / `quad` / 着色器 `VS` `FS` `FVS` `FFS` / `camera` / `hlChar`。
**长出来的东西要为这一课现写**：`TREES`、`PANS`、`LEAFS`、配色表 `PAL_*`、落点。换一课就是换一样东西长出来，可能是树、月亮、小船……照第三节的六条重新设计，先出几种长法给用户挑。

## 八、坑（都踩过）

- 左边那一沓的落页角写反（`thEnd` 的符号），左页会往上翘。
- 页面背面的贴图 x 要翻转。拼接改着色器时漏了 `uniform1i(uF/uB/uM)`，背面会显示成正面的图。
- 小花每个顶点要共用同一个随机数（`rz`）；每个顶点各取一次 `R()`，风一吹就被扯成碎片。
- 相机关键帧要挂在 `marks` 上（`CAM[2] = burst`），别挂在写死的拍上，不然换了旁白，镜头和花对不上。
- 用了图片素材，要重定义 `window.READY` 的 getter，等贴图读完再放行渲染。
- 旁白切得太碎，会把两截之间的叹气切掉；现在每截前留 0.2 s 吸气，叹气在停顿中间也保得住。
- 对八分音符会把停顿撑到 0.6 s 以上，听起来拖。
- 课本页面和插图是出版社的版权：只放在用户自己的工程里，**不进 skill**（这个仓库是公开的）。示例不带 `assets/`。
- 没有 PDF 渲染器就装 `pypdfium2`：`pip install --user pypdfium2`。

## 九、返工话术

| 用户说 | 改什么 |
|---|---|
| 像从中间突然冒出来、杂乱 | 不要碎片飞起，改成从画里的枝条处破纸长 |
| 像五角星 / 太圆 | 出几种长法让用户挑；花序方向往上收、轮廓取中间 |
| 颜色太重 / 最后变白 | 取画上的颜色、调浅；去掉变色，花苞颜色 ≈ 开花颜色 |
| 长完以后不自然 | 改成一阵微风、落花，顺带推近 |
| 翻书再快一些 | 每张纸落在八分音符上；第 2 拍停在目标页 |
| 两句语气不一样 | 两句一次生成；表演指导写"same tone throughout" |
| 某一句突然扬起来 | `stats` 量那一截；`act` 里点名压住那句，出 3 版挑最平的 |
| 停顿、呼吸太多 | 截间停顿上限 0.55 s，对十六分音符；表演指导去掉"sigh / breathy" |
| 配音太快 / 太慢 | 不变速（会失真）；改片长（多几拍）或删字，不改配乐 |
| 混响好，都不要太过 | t60 0.75 / wet 0.1，不再加 |

## 十、交片前检查

| | 门槛 |
|---|---|
| 书 | 每一页都是 PDF 原页；配对和真书一致；左页不翘；背面不错图 |
| 长出来 | 从画里的位置长；形状查证过；颜色像画；没有变白；画淡了、有投影 |
| 卡点 | 第一截在第 0 拍；花全开 = 最重的军鼓 = 念到关键词；第二句第一个字落在军鼓上；荧光笔跟着旁白 |
| 声音 | 每截音高测过（长截没有 ≥ +1.5 半音）；停顿 0.2–0.65 s；混响轻；配乐说完才渐弱 |
| 交付 | 三样都在；"完整版 − 动效配音 − 配乐"的残差 ≈ 0；时长 ≤ 20 s |
